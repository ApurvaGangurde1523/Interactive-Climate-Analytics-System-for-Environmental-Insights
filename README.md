# Interactive-Climate-Analytics-System-for-Environmental-Insights
![Climate Dashboard](screenshots/dashboard.png)

This project presents a Climate Change Dashboard designed to analyze and 
visualize key environmental indicators such as temperature, air quality index 
(AQI), humidity, precipitation, and extreme weather events across multiple 
countries. 
The dashboard integrates data from various sources and transforms it into 
interactive visualizations using tools like Tableau. It enables users to 
identify trends, compare regional patterns, and gain insights into climate 
variability. 
The system incorporates features like filtering, drill-down analysis, and 
interactive charts to enhance user experience. The primary objective is to 
provide a comprehensive and user-friendly platform for understanding climate 
data and supporting informed decision-making.
